# yii2-cms-route-alias

Управляемые из админки короткие («красивые») URL фронтенда для Yii2 CMS. Админ задаёт литеральный
короткий путь и выбирает цель (модуль → базовый роут → slug); одно класс-правило `UrlRuleInterface`
работает в обе стороны на основе **точного сопоставления** по таблице (никаких пользовательских
регекспов). Подробности и обоснование — в [PLAN.md](PLAN.md).

## Как это работает

- Во вьюхах — обычные `Url::to(['/Module/controller/action', ...])`.
- Модуль включён → там, где заведён алиас, в адресной строке короткий URL; для остального — обычные URL.
- Модуль выключен (modman) → правило исчезает из `frontendUrlManager`, маршрутизация возвращается к
  обычной. **Ничего не падает** — прозрачный fallback. Модуль не является критичной зависимостью.

## Установка

```bash
sudo -u www-data php yii Modman/modules/install RouteAlias
```

После установки на проде обновить FPM-код: `systemctl reload php8.4-fpm` (OPcache),
из админки самоинвалидируется автоматически.

## Главная страница

Флажок «Главная страница» в форме алиаса: цель открывается по `/` (в БД это пустой `path`, главная одна).
Ссылки на цель (`Url::to`), canonical и sitemap получают `/`.

## Канонический адрес (301)

Правило алиасов ставится первым в `frontendUrlManager` из `Bootstrap` — иначе правила модулей
(`page/<slug>`) перехватывают генерацию URL. Во фронтенде страница с алиасом, открытая по другому адресу
(`/page/home`, `/Page/page/view?slug=home`, `/PRICE`, `/price/`), отвечает 301 на алиас; query-параметры
(utm и т.п.) сохраняются. Подробности — в [PLAN.md](PLAN.md).

## Провайдеры целей

Модуль показывает в админке только те цели, которые модули объявили сами, реализовав контракт
`Besnovatyj\Contracts\routing\AliasTargetProvider` (метод класса Yii-модуля). Пилот — модуль `Page`
(`Page/page/view`, `Page/page/group`). Чтобы добавить свой модуль:

```php
class Module extends CmsModule implements /* ... */ AliasTargetProvider
{
    public function aliasTargets(): array
    {
        return [new AliasTarget('/My/thing/view', 'Моя сущность', 'slug')];
    }

    public function aliasSlugs(string $route): array
    {
        return ['some-slug' => 'Подпись']; // slug => подпись для выпадающего списка
    }
}
```

## Производительность

Все активные алиасы грузятся одним элементом кэша (APCu) с тегом `route_aliases`; инвалидация — в
`Bootstrap` на AR-событиях. На горячем пути парсинга/генерации URL — array-лукапы, запросов к БД нет.

## Зарезервированные префиксы

`params.reservedPrefixes` (см. `config/config.php`) запрещает занимать короткими URL системные/модульные
префиксы. Расширяется под конкретный проект.
